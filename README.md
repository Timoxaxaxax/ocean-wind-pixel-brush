# Револьвер «Бульдог» KURS

Одностраничный сайт продажи КСОИ «Бульдог» завода KURS. Единственный контакт — Telegram: https://t.me/kurs_buldog_ru

Изделие по сертификату производителя **не является оружием**. На сайте нет инструкции по доработке и нет призывов применять его против людей.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на порту 8080. Сборка: `npm run build`.

## Что поменять перед публикацией

Все настройки — в [`src/lib/site.ts`](src/lib/site.ts):

| Поле | Зачем |
| --- | --- |
| `url` | Постоянный адрес сайта, например `https://buldog.ru`. Нужен для канонической ссылки. Если оставить пустым, подставится домен, с которого открыли страницу. |
| `priceRub` | Цена в рублях. `null` — на странице будет «цена по запросу». |
| `yandexVerification` | Код из Яндекс.Вебмастера (мета-тег). |
| `metrikaId` | Номер счётчика Яндекс.Метрики. |
| `telegram` | Ссылку менять не нужно, если канал тот же. |

Свои фото кладите в `public/photos/` под теми же именами:

- `buldog-profil.jpg`
- `buldog-rakurs.jpg`
- `buldog-baraban.jpg`
- `buldog-rukoyat.jpg`

Подписи и alt уже стоят в `src/lib/site.ts`.

## Как выложить на GitHub

```bash
git init
git add .
git commit -m "Сайт Бульдог KURS"
git branch -M main
git remote add origin git@github.com:ВАШ-АККАУНТ/buldog-kurs.git
git push -u origin main
```

Репозиторий — это исходники. Самому GitHub Pages нужен статический экспорт, а этот проект работает как Node-приложение (Vite + TanStack Start). Проще всего подключить репозиторий к [Vercel](https://vercel.com): он подхватит `vercel.json` и соберёт сайт сам. После деплоя привяжите свой домен — для Яндекса это важнее, чем адрес вида `username.github.io`.

## Чтобы Яндекс показал сайт

Техническая оптимизация уже в проекте. Поисковик не ставит новый домен на первое место в день публикации: его нужно отдать на обход и дождаться, пока страница попадёт в индекс. Конкуренция по запросу «бульдог курс» плотная, поэтому делайте шаги по порядку.

1. Опубликуйте сайт на **постоянном https-домене** и впишите его в `site.url`.
2. Откройте [Яндекс.Вебмастер](https://webmaster.yandex.ru/), добавьте сайт и подтвердите права. Код подтверждения вставьте в `yandexVerification`.
3. В Вебмастере укажите sitemap: `https://ВАШ-ДОМЕН/sitemap.xml`. Файл собирается сам, в нём есть и картинки.
4. `robots.txt` тоже отдаётся сам: для Яндекса прописаны `Host`, `Clean-param` (чтобы метки рекламы не плодили дубли) и ссылка на карту.
5. Создайте счётчик в [Яндекс.Метрике](https://metrika.yandex.ru/) и впишите номер в `metrikaId`. Поведенческие факторы Яндекс видит именно так.
6. После выкладки один раз откройте в браузере (ключ уже лежит в `public/`):

   `https://yandex.com/indexnow?url=https://ВАШ-ДОМЕН/&key=kursbuldog8f3a1c9e4b27`

   IndexNow просит Яндекс зайти на страницу быстрее, но не гарантирует место в выдаче.
7. В Вебмастере нажмите «Переобход страниц» для главной.
8. Проверьте в «Просмотр страницы роботом», что Яндекс видит заголовок, текст, FAQ и фото, а не пустой экран.

Что уже сделано в коде и помогает ранжированию:

- один понятный `title` и description под запросы «револьвер бульдог курс», «купить», «без лицензии», «КСОИ»;
- один `h1`, дальше заголовки второго уровня с теми же формулировками, без скрытого текста;
- уникальный текст, таблица характеристик, комплект, доставка, оплата, гарантия, возраст 18+ — коммерческие факторы, которые Яндекс ждёт на странице товара;
- блок вопросов в разметке `FAQPage` и карточка `Product` (Schema.org);
- `lang="ru"`, канонический адрес, `X-Robots-Tag: index, follow`;
- фото с нормальными именами файлов, размерами и alt;
- страница быстрая и нормально открывается с телефона.

Чего код сделать не может: купить ссылки, состарить домен и обойти магазины, которые уже год в индексе. После индексации имеет смысл просить тематические площадки сослаться на сайт обычной ссылкой и не дублировать тот же текст на других доменах.

## Юридически

Тексты опираются на открытые характеристики производителя KURS. Перед продажей сверяйте сертификат партии. Сайт не обещает, что правила всех регионов совпадают с сертификатом.
